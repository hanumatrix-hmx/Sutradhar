Custom pointer-based drag (no native HTML5 draggable/dataTransfer at all)

Many real Kanban/workflow-builder UIs implement drag this way — a real, high-level "drag and drop" API built around HTML5 dragstart/dragover/drop events does nothing here; the only thing that works is a genuine mousedown → mousemove (crossing the target's bounding box) → mouseup sequence, since that's literally the only thing this page listens for.
