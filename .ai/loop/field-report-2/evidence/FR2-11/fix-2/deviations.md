# FR2-11 fix-2 deviations from the Orchestrator's revised plan (and decisions the plan left open)

The plan was implemented as written. Where the plan was silent or a hard requirement forced a detail, this is what was done and why.
Each item is pinned by a test named in the last column.

| # | Plan said | What was built | Why | Pinned by |

| D-fix2-1 | (a) "cut from the first `?` `#` `;`, replace the rest with the placeholder" | The rest of the TEXT after the cut (all later tokens of the same string) is dropped, not only the rest of the token.
