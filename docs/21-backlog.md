# Project Feature & Technical Backlog

## Prioritized Feature Backlog

1. **Multi-Tab Parallel Task Execution**: Enable agents to spawn concurrent tabs and execute parallel sub-tasks.
2. **Audio/Voice Agent Control**: Real-time voice prompt streaming and speech synthesis.
3. **Visual Workflow Canvas Editor**: Drag-and-drop node graph UI in `apps/web` for constructing deterministic automation pipelines.
4. **Cloud Plugin Marketplace**: Registry interface for downloading community tool and provider packages.
